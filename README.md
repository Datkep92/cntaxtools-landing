# CN Tax Tools (CNTaxTools)

**CN Tax Tools** (viết liền: **CNTaxTools**) là trang giới thiệu ứng dụng hỗ trợ kế toán trên Windows 10/11 64-bit. Miễn phí trong giai đoạn phát triển.

- Tải hóa đơn mua vào/bán ra và quản lý nhiều MST.
- Xem PDF, tra cứu và tải PDF gốc từ nhà cung cấp.
- Lọc hóa đơn, hàng hóa, đối tác và xuất Excel.
- Nhập sao kê, kiểm tra dòng tiền và đối chiếu chứng từ.
- Theo dõi tổng quan, công nợ và tổng hợp số liệu GTGT.
- Tra cứu MST, tải tờ khai và lưu hồ sơ.
- AI hỗ trợ đọc file, phân tích, so sánh và chuẩn bị báo cáo.
- Chuẩn bị dữ liệu và file thay thế hóa đơn theo mẫu MISA; kiểm tra trước khi nhập hoặc phát hành.

[Xem trang giới thiệu](https://cntaxtools.com/) · [Tải bản mới](https://github.com/Datkep92/HoaDonNhe/releases/latest) · [Liên hệ Admin](https://zalo.me/0395995035)

## Chỉnh sửa trang

Trang tĩnh: nội dung trong index.html, mô tả slide trong assets/js/main.js, giao diện trong assets/css/style.css. Nút tải tự nhận bộ cài mới nhất từ GitHub Releases. Giữ thông tin SEO và site.webmanifest đồng bộ với nội dung hiển thị.
