# Bắt đầu deploy CN Tax Tools Landing Page

## Tóm tắt nhanh

1. Tạo repository trên GitHub
2. Push code lên repository
3. Bật GitHub Pages
4. Truy cập website

## Hướng dẫn chi tiết

Xem file [HUONG_DAN_DEPLOY.md](HUONG_DAN_DEPLOY.md) để biết chi tiết từng bước.

## Cấu trúc files

```
landing-page/
├── index.html              # Trang chính
├── styles.css              # Styles chính
├── script.js               # JavaScript
├── .nojekyll               # Bỏ qua Jekyll processing
├── .gitignore              # Files bỏ qua khi commit
├── .github/
│   └── workflows/
│       └── deploy.yml      # GitHub Actions workflow
├── assets/                 # Hình ảnh, icons
│   ├── app-screenshot.svg
│   ├── avatar-1.svg
│   ├── avatar-2.svg
│   └── avatar-3.svg
├── README.md               # Hướng dẫn cơ bản
├── DEPLOY.md               # Hướng dẫn deploy chi tiết
├── QUICKSTART.md           # Hướng dẫn nhanh
├── HUONG_DAN_DEPLOY.md     # Hướng dẫn deploy bằng tiếng Việt
└── START_HERE.md           # File này
```
